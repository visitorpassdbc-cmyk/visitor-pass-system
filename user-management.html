✉️ Email Notification Settings
ℹ️ This system uses EmailJS to send email notifications directly from the browser without a backend server.

Setup Steps:
1. Create a free account at emailjs.com
2. Create an Email Service (Gmail, Outlook, etc.) → copy the Service ID
3. Create an Email Template → copy the Template ID
4. Go to Account → API Keys → copy the Public Key
5. In the template, use these variables: {{to_email}}, {{to_name}}, {{subject}}, {{message}}
6. Fill in the form below and save.
Enable Email Notifications

🌐 Online Sync Configuration (Firebase)
ℹ️ Connect your system to a cloud database so that HODs, Directors, and Security officers can view, approve, and track visitor passes in real-time from their own devices, anywhere.

Setup Steps:
1. Go to Firebase Console and create a free project.
2. Add a Web App to your project and copy the firebaseConfig details.
3. In the Firebase console, go to Firestore Database and create a database in Test Mode (or set Security Rules to allow read/write access).
4. Paste the configuration fields below, check "Enable Firebase Real-time Cloud Sync" and save.
Enable Firebase Real-time Cloud Sync
🔄 Database Migration & Sync

If this is your first time enabling Cloud Sync, upload your local data to the cloud. You can also download cloud records to overwrite your local cache.
